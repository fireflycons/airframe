# README Documentation Guidelines

## 1. Core Principles
- **Exclude simple layout and design changes**:
  - Do not record simple UI or internal changes in the README, such as moving buttons, adjusting margins, editing label text, or internal build scripts.
  - Cover such changes only in `CHANGELOG.md` or commit messages, where needed.

## 2. Focus on Features
- List only the core features that users actually use.
- Write so that each feature's name and core purpose are immediately clear.

## 3. Keep It Extremely Concise
- Exclude all verbose or decorative wording.
- Instead of needlessly long sentences, use only concise one-line bullet points that carry the key point.
